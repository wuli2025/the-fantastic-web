# Igloo 原始安装包与中文学习文档

提供两个原始 ZIP 下载，并将完整工程展开到仓库，方便直接阅读和修改代码。

| 附件 | 用途 | 运行方式 |
| --- | --- | --- |
| `Igloo网页发布版.zip`，17.03 MiB | 直接体验网站 | 完整解压，安装 Node.js 18+，Windows 双击 `启动网站.cmd`；其他系统执行 `node serve.mjs` |
| `Igloo完整项目.zip`，21.16 MiB | 开发与学习 | Node.js 22.12+ 或 20.19+，解压后执行 `npm install`、`npm run dev` |
| `SHA256SUMS.txt` | 校验原包完整性 | 与本地文件的 SHA-256 比较 |

默认首页是 Igloo 完整体验，`/forma.html` 是独立的宇航员、舞者与奔跑者粒子实验。普通 `index.html` 需要通过本地服务器访问。

新增文档在仓库中，两个 ZIP 保留用户提供的原始内容：

- [效果实现原理](https://github.com/wuli2025/the-fantastic-web/blob/main/docs/HOW_IT_WORKS.zh-CN.md)：冰晶、滚动合成、体积粒子、人物采样、GPU 变形、鼠标交互和声音。
- [修改指南](https://github.com/wuli2025/the-fantastic-web/blob/main/docs/CUSTOMIZE.zh-CN.md)：修改位置、具体参数、增加人物、GLB 与性能改进。
- [下载与运行说明](https://github.com/wuli2025/the-fantastic-web/blob/main/docs/DOWNLOADS.zh-CN.md)：原包区别、启动步骤、校验与部署。

已完成干净依赖安装和构建；生成的 122 个构建文件与网页发布版 ZIP 内对应文件逐字节一致。两个 ZIP 已通过完整性检查，原站资源也按清单检查：109 个原文件哈希一致，另两个 JS 是已有的本地适配版本。

Igloo 部分是原站公开生产构建的本地复现，不含原作者开发源码和建模工程；FORMA 为可读源码。第三方 Hologram 学习目录需要独立安装与启动，本次没有验证该子项目运行。来源和已有许可说明均保留。

当前发布托管代码和下载包，尚未开通 GitHub Pages；根路径资源和详情路由需要额外适配才能部署到 Pages 项目子路径。两个 ZIP 不包含原桌面环境中提到的单文件 HTML；可在完整工程中通过 `npm run export:html` 自行生成。
